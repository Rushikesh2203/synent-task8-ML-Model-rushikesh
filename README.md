House Price Prediction using Machine Learning

Project Overview

This project builds a Machine Learning model to predict house prices based on various housing features such as area, number of bedrooms, bathrooms, and other property characteristics.

The goal is to develop an accurate predictive model that can estimate house prices using historical housing data.

---

Objectives

- Perform data preprocessing
- Handle missing values
- Select relevant features
- Train machine learning models
- Evaluate model performance
- Predict house prices

---

Dataset

Dataset: House Price Dataset

Source: Kaggle

---

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn
- Jupyter Notebook

---

Workflow

1. Data Collection
- Load housing dataset

2. Data Preprocessing
- Handle missing values
- Encode categorical variables
- Feature scaling

3. Exploratory Data Analysis
- Correlation analysis
- Feature distribution analysis

4. Model Building
Models Implemented:
- Linear Regression
- Random Forest Regressor

5. Model Evaluation
Evaluation Metrics:
- R² Score
- RMSE
- MAE

6. Prediction
- Predict house prices based on user-defined inputs

---

Results

- Successfully trained and evaluated regression models.
- Compared model performance using multiple evaluation metrics.
- Generated accurate house price predictions.
